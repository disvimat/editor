# Añadir una lengua a DISVIMAT (módulo E6)

El español es la lengua de referencia: si falta algo en otra lengua, el
programa recurre al español sin fallar. La localización tiene dos capas
independientes:

## 1. Las tablas por lengua (verbalización, braille)

Todo lo que el editor dice o transcribe sale de tablas con sufijo de
lengua en [data/](../data/README.md). Para una lengua nueva (p. ej.
francés, `fr`), copiar y traducir:

| Copiar | Como | Contenido |
|--------|------|-----------|
| `etiquetas.es.json` | `etiquetas.fr.json` | verbalización (B2) |
| `br6.es.json` | `br6.fr.json` | braille de los elementos (B5) |
| `br6_texto.es.json` | `br6_texto.fr.json` | braille de letras y dígitos |

En cada copia, poner `"lengua": "fr"` en la envoltura y traducir los
valores (nunca los `id`, que son invariables).

## 2. Las cadenas de la interfaz (gettext)

Los menús, diálogos y títulos de ventana pasan por gettext
([i18n.py](../src/disvimat/core/i18n.py)). La plantilla de mensajes es
[src/disvimat/locale/disvimat.pot](../src/disvimat/locale/disvimat.pot).

```
# 1. Crear el catálogo de la lengua a partir de la plantilla
mkdir -p src/disvimat/locale/fr/LC_MESSAGES
cp src/disvimat/locale/disvimat.pot src/disvimat/locale/fr/LC_MESSAGES/disvimat.po

# 2. Rellenar los msgstr del .po con la traducción

# 3. Compilarlo (msgfmt viene con gettext; en Windows, con Poedit o
#    con python Tools/i18n/msgfmt.py)
msgfmt src/disvimat/locale/fr/LC_MESSAGES/disvimat.po \
    -o src/disvimat/locale/fr/LC_MESSAGES/disvimat.mo
```

Al añadir cadenas nuevas al código (siempre envueltas en `_(...)`),
añadirlas también a `disvimat.pot`.

## 3. Arrancar en otra lengua

```
set DISVIMAT_LENGUA=fr
python -m disvimat.desktop
```

(También existe `DISVIMAT_PERFIL` para el perfil de usuario A7:
`inicial`, `medio` o `avanzado`.)

## Reglas para el código

- El núcleo **no** contiene texto para el usuario: verbaliza y presenta
  solo con las tablas. Si un mensaje nuevo del núcleo debe llegar al
  usuario, se añade a las tablas, no como cadena en el código.
- La interfaz solo muestra texto envuelto en `_(...)` o procedente de
  un `Resultado` del núcleo.
- Los nombres canónicos de teclas ("Ctrl+F", "Left") no se traducen.
